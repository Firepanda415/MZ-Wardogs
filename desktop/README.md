# MZ Wardogs Overlay（Windows）

双击便携目录中的 `MZ-Wardogs-Overlay.exe`。整个目录需放在一起。地图和道路随程序携带，运行无需 Node.js、手机或本地网页服务器。

## 使用

1. 游戏设为无边框窗口模式。打开工具，在地图中选择武器、自己和目标坐标。
2. 小窗默认约 440 × 570（Windows 150% 缩放时约 660 × 855 屏幕像素），可拖动标题栏、拖动边框缩放。默认不透明度为 80%（约 20% 透过背景），顶部滑块越往右越实，会记住你的调整；点击「鼠标穿透」后，鼠标交给下方游戏。
3. L81 选择有效目标后，按 **~+F2** 开启全屏透明瞄具。地图和计算面板保持显示并位于覆盖层上方，修改目标后刻线同步更新。将游戏中央准星与覆盖准星对齐，再将游戏刻度与两侧同值刻线调到同一高度；方位按顶部中央数字调整。文字和刻线为白色黑边，距离在左，MIL 在右。
4. **~+F1** 进入校准，可以调比例、左右/上下偏移；再次按下恢复鼠标穿透。设置自动保存。

顶部「简略版」切换到宽约 440、高度随内容自动收紧的炮击小窗，保留地图选择、武器、射程、距离、方位与坐标；收藏按钮位于快捷键提示栏右侧。不显示地图画布、导航或界面内的模拟瞄具。全屏瞄具仍由「全屏瞄具」或 **~+F2** 开关。点击「完整版」恢复原窗口和地图状态，坐标不丢失；下次启动记住所选版本。地图下拉选择与完整版共用各地图的坐标和收藏。

| 快捷键 | 功能 |
| --- | --- |
| ~+F1 | 交互 / 鼠标穿透；全屏时为校准 / 穿透 |
| ~+F2 | 瞄具开 / 关，保留地图面板 |
| ~+F3 | 地图和瞄具一起隐藏 / 显示 |
| ~+F4 | 切回工具面板，恢复交互并获取焦点 |

`~` 指数字 1 左边的物理键：直接按住它，再按 F1/F2/F3/F4，**不需要按 Shift**。单按这些 F 键不触发工具。退出使用窗口 × 或托盘菜单。

游戏仍在捕获鼠标、无法点击面板时，按 **~+F4** 切回工具。面板即使已隐藏、最小化或处于鼠标穿透状态，也会恢复显示和交互。全屏瞄具保持当前开关状态。

右下角系统托盘的 M 图标可以随时找回地图或退出。若快捷键组件未能启动，顶部会提示，仍可用按钮和托盘。将地图窗口移到游戏所在显示器，再打开全屏瞄具。

全屏模式是透明桌面窗口，不会读取游戏坐标。独占全屏、游戏反作弊环境下的可见性需实际测试。每次启动均恢复交互模式，可直接操作面板。

## 瞄具标定

- 参考已有 3840 × 2160 截图：准星中心 `(1919.5, 1079.5)`，50 MIL 间隔 **204 px**。覆盖当前显示器全部区域，方位在顶部中央，两侧读数按屏幕宽度布局；准星及 MIL 间隔按屏幕高度等比缩放，适配 16:9、4:3、超宽和竖屏，不横向拉伸。校准比例只调整准星与刻线间距，两侧文字保持在屏幕内。
- Windows 显示缩放由 Chromium 处理；校准面板的偏移单位为窗口逻辑像素。不同游戏 HUD/FOV 设置可用比例和偏移修正。
- 顶部罗盘以目标方位居中：上排为模拟刻度（每 5° 一小格、15° 标注数字），下排为精确目标方位文字，方便与游戏罗盘对比。跨越正北时按 359°→0° 连续排列，窄屏减少可见角度范围。
- 共用 `core.mjs` 的截图刻度和线性插值；只在 L81 可用范围 120–684 m 显示对齐线，SPH-2 或无效坐标显示提示。
- 覆盖线表示目标距离对应的游戏刻度，并非自动瞄准或实际命中保证；尚需游戏内对齐验证。

收藏与坐标保存在本程序的独立档案 `%APPDATA%/MZ-Wardogs-Overlay`，不会自动读取 Chrome 的收藏。窗口布局和校准保存在其中的 `overlay.json`。

## 从源码运行 / 打包

需要 Node.js **22.12 或更高版本**。在 `desktop` 目录执行：

```powershell
npm ci
npm start
npm test
npm run build
```

安装依赖后，也可双击仓库根目录 `Start Overlay.cmd`。快捷键组件由 Windows 自带的 .NET Framework 编译器构建，便携包已包含编译结果。

`npm run build` 同时输出便携目录 `desktop/dist/MZ-Wardogs-Overlay/` 和 `desktop/dist/MZ-Wardogs-Overlay-v<版本>-win-x64.zip`，将 ZIP 上传到 Release 即可。包含全部离线地图，体积较大。构建前退出正在运行的旧便携版；构建不会删除现有目录。仅做开发构建可运行 `node build.mjs --no-zip`。

## 数据更新

网页版和桌面开发版共用仓库根目录的 `core.mjs`、`roads-*.mjs`、`routing.mjs`、`assets/maps/` 及页面代码。**只改这一份公共源文件**，没有另一份需要手工维护的桌面数据。

Release ZIP 是构建时的离线快照，不会随线上网页自动更新。修改公共数据并通过测试后，发布网页，再运行 `npm run build` 生成新的桌面 ZIP。用户解压新包，个人坐标、收藏和校准继续从 `%APPDATA%/MZ-Wardogs-Overlay` 读取，不随程序目录覆盖而丢失。

`npm test` 使用独立临时档案，实开窗口检查本地资源、路由、数据传递、截图刻度、隐藏/显示、透明度和快捷键，不改用户收藏。

窗口能力使用 [Electron BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window)，本地资源通过 [protocol.handle](https://www.electronjs.org/docs/latest/api/protocol) 加载。Electron/Chromium 的许可证包含在便携目录，地图归属见 `resources/app/web/THIRD_PARTY_NOTICES.md`。
