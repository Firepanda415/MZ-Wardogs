# Overlay 示例素材

所有图片保留 3840×2160 原始尺寸。

| 文件 | 用途 |
| --- | --- |
| `mortar.jpg` | 未叠加 Overlay 的迫击炮瞄准画面，作为炮击示例底图 |
| `game.jpg` | 未叠加 Overlay 的道路行驶画面，作为导航示例底图 |
| `mortar_full.png` | 迫击炮瞄准画面 + 全屏辅助准星 + 完整版面板 |
| `mortar_short.png` | 迫击炮瞄准画面 + 全屏辅助准星 + 简略版面板 |
| `guide.png` | 道路行驶画面 + 路线导航面板 |

## 截图维护

仅在 UI 变化时更新对应示例。道路、坐标、计算数据等不影响 UI 的变更无需更新截图。更新示例时复用两张 JPG 底图，保留原始尺寸；JPG 底图不覆盖为带 Overlay 的合成图。

项目 README 展示三个 PNG 示例，按完整版炮击、简略版炮击、道路导航排列。说明文字描述使用场景与可见功能，不包含开发对话或修改过程。
